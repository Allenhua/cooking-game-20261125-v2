Sizzle & Serve is a fast, friendly burger-bistro cooking game: run a 3-minute shift, grill patties, chop veggies, stack burgers to match the order board, and serve each dish before its ticket runs out — chain quick serves into combos while the lunch rush speeds up.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## How to play

- **Move:** WASD / arrow keys, or click the floor to walk there.
- **Grab:** click an ingredient bin, or press 1–8.
- **Cook:** click the grill (patties), the fryer (fries) or the chopping board (lettuce, tomato, onion) — patties burn if you leave them too long.
- **Build:** click the plate to add a ready ingredient; click the trash to start the dish over.
- **Serve:** click an order ticket (or press Space) when the plate matches it. Fast serves and combos earn bonus points; expired orders cost a heart.
- **Pause:** P · **Mute:** M · **Restart:** R.
